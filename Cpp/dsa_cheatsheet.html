🧩Disjoint Set (DSU)O(α(n)) ≈ O(1)
struct DSU { vector<int> p, rank; DSU(int n):p(n),rank(n,0){iota(p.begin(),p.end(),0);} int find(int x){ return p[x]!=x?p[x]=find(p[x]):x; } bool unite(int x,int y){ x=find(x);y=find(y); if(x==y)return false; if(rank[x]<rank[y])swap(x,y); p[y]=x; if(rank[x]==rank[y])rank[x]++; return true; } };
⚡ unite() returns false → cycle! (Kruskal's / redundant edge)
🌸Bloom FilterProbabilistic
Bit array + k hash functions. Space-efficient membership test.
ResultMeaning
All k bits = 1Maybe present (FP possible)
Any bit = 0Definitely absent
// FP rate ≈ (1 - e^(-kn/m))^k // n = items inserted // m = bit array size // k = # hash functions // Cannot delete! (→ Counting BF) // Used: Chrome safe browse, CDN
⚡ No false negatives. FP rate decreases with larger m.

🚨 Common Interview Gotchas
MistakeFix
Using map[key]++ without checkUse map.count(key) or map.find(key) first to avoid ghost keys
Reading pop() return valuestack/queue/pq pop() returns void — save top()/front() before pop()
BST validate without boundsPass (lo, hi) range — not just comparing to parent
Overflow in sum / mid calculationUse long long; mid = lo + (hi-lo)/2 not (lo+hi)/2
DFS on graph without visited[]Always mark visited before pushing — not after popping
Heap delete-by-valuePQ doesn't support it — use lazy deletion with a "dead" set
DSU without path compressionAlways use both path compression AND union by rank
Modifying vector while iteratingUse index-based loop or collect changes and apply after
