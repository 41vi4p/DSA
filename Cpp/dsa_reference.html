Array

std::vector / int arr[] / std::array
Contiguous O(1) access Cache-friendly

What it is

A fixed or dynamic sequence of elements stored in contiguous memory. The foundation of nearly all algorithms. Random access in O(1) via index arithmetic.

When to use

  • Need fast random access by index
  • Iteration over all elements
  • Prefix sums, sliding windows, two pointers
  • As backing store for other structures
OperationTimeSpace
Access by indexO(1)O(1)
Search (unsorted)O(n)O(1)
Search (sorted, binary)O(log n)O(1)
Insert at end (vector)O(1) amortizedO(1)
Insert at middleO(n)O(1)
Delete at middleO(n)O(1)
C++array essentials
// Static array
int arr[5] = {1, 2, 3, 4, 5};

// Dynamic array (preferred)
vector<int> v = {1, 2, 3};
v.push_back(4);       // O(1) amortized
v.pop_back();          // O(1)
v[2];                  // O(1) access
v.size();              // number of elements
sort(v.begin(), v.end());  // O(n log n)

// Two-pointer pattern (sorted array)
int l = 0, r = v.size() - 1;
while (l < r) {
    if (v[l] + v[r] == target) { /* found */ break; }
    else if (v[l] + v[r] < target) l++;
    else r--;
}

// Prefix sum (range sum in O(1))
vector<int> prefix(n + 1, 0);
for (int i = 0; i < n; i++)
    prefix[i+1] = prefix[i] + arr[i];
// Sum from l to r: prefix[r+1] - prefix[l]
⚡ Interview Traps
  • Sliding window and two-pointer are the most common array patterns
  • Off-by-one errors on bounds — always double-check i < n vs i <= n
  • Use INT_MAX / INT_MIN as sentinels; mention overflow risk
  • Mention reserve() to avoid reallocations in hot loops

Linked List

std::list / std::forward_list / custom node
O(1) insert/delete O(n) access No contiguous memory

What it is

Nodes linked via pointers. Singly linked (next only), doubly linked (next + prev), or circular. Insertion/deletion at known pointer is O(1) — no shifting.

When to use

  • Frequent insertions/deletions in the middle
  • Implementing stacks, queues, LRU Cache
  • When size is unknown / highly dynamic
  • When pointer stability matters
OperationSinglyDoubly
Access / SearchO(n)O(n)
Insert at headO(1)O(1)
Insert at tail (with tail ptr)O(1)O(1)
Delete at known nodeO(n)*O(1)
C++singly linked list + classic patterns
struct Node {
    int val;
    Node* next;
    Node(int v) : val(v), next(nullptr) {}
};

// Reverse a linked list (iterative)
Node* reverse(Node* head) {
    Node* prev = nullptr, *curr = head;
    while (curr) {
        Node* nxt = curr->next;
        curr->next = prev;
        prev = curr; curr = nxt;
    }
    return prev;
}

// Detect cycle — Floyd's tortoise & hare
bool hasCycle(Node* head) {
    Node* slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}

// Find middle node
Node* findMid(Node* head) {
    Node* slow = head, *fast = head;
    while (fast->next && fast->next->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow; // slow is the middle
}
⚡ Interview Traps
  • Always check for null head and single-node edge cases
  • Fast/slow pointer (Floyd's) solves: cycle, middle, nth-from-end
  • Dummy head node simplifies insertion/deletion logic at head
  • For merge sort on LL — find mid, split, sort halves, merge

Stack

std::stack / LIFO — Last In First Out
O(1) push/pop LIFO Backtracking

What it is

A LIFO structure. Push adds to top, pop removes from top. Used wherever you need to "undo", track state, or process the most-recently-seen item.

Classic use cases

  • Balanced parentheses / bracket matching
  • Next Greater Element (monotonic stack)
  • DFS iteratively
  • Expression evaluation (infix → postfix)
C++stack + monotonic stack pattern
stack<int> st;
st.push(5);      // push
st.top();       // peek — no removal
st.pop();       // remove top (returns void!)
st.empty();     // check empty
st.size();      // element count

// Valid parentheses
bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '{' || c == '[') st.push(c);
        else {
            if (st.empty()) return false;
            char top = st.top(); st.pop();
            if (c == ')' && top != '(') return false;
            if (c == '}' && top != '{') return false;
            if (c == ']' && top != '[') return false;
        }
    }
    return st.empty();
}

// Monotonic stack — Next Greater Element
vector<int> nextGreater(vector<int>& nums) {
    int n = nums.size();
    vector<int> res(n, -1);
    stack<int> st; // stores indices
    for (int i = 0; i < n; i++) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            res[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }
    return res;
}
⚡ Interview Traps
  • Monotonic stack solves: NGE, daily temperatures, largest rectangle in histogram
  • st.pop() returns void — save top before popping
  • Implement stack with two queues / min-stack are classic problems

Queue

std::queue / FIFO — First In First Out
O(1) enqueue/dequeue FIFO BFS

What it is

FIFO — enqueue at back, dequeue at front. The natural structure for BFS because it processes nodes level-by-level.

When to use

  • BFS on trees and graphs
  • Level-order traversal
  • Task scheduling, producer-consumer
  • Sliding window maximum (with deque)
C++queue + BFS template
queue<int> q;
q.push(1);      // enqueue
q.front();     // peek front
q.back();      // peek back
q.pop();       // dequeue (returns void)
q.empty();

// BFS template (graph/tree)
void bfs(int start, vector<vector<int>>& adj) {
    vector<bool> visited(adj.size(), false);
    queue<int> q;
    q.push(start);
    visited[start] = true;
    while (!q.empty()) {
        int node = q.front(); q.pop();
        // process node
        for (int nb : adj[node]) {
            if (!visited[nb]) {
                visited[nb] = true;
                q.push(nb);
            }
        }
    }
}

// Priority queue (max-heap by default)
priority_queue<int> maxPQ;
priority_queue<int, vector<int>, greater<int>> minPQ;

Deque

std::deque — Double-Ended Queue
O(1) both ends Sliding window

What it is

Push and pop from both front and back in O(1). More flexible than queue or stack. Used for the sliding window maximum problem with a monotonic deque.

When to use

  • Sliding window maximum/minimum
  • BFS where priority matters at front
  • Palindrome checking
  • 0-1 BFS (Dijkstra variant)
C++deque + sliding window max
deque<int> dq;
dq.push_back(1);   dq.push_front(0);
dq.pop_back();     dq.pop_front();
dq.front();        dq.back();

// Sliding window maximum (k-size window)
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> dq;  // stores indices (decreasing values)
    vector<int> res;
    for (int i = 0; i < nums.size(); i++) {
        // remove out-of-window indices
        if (!dq.empty() && dq.front() <= i - k) dq.pop_front();
        // maintain decreasing order
        while (!dq.empty() && nums[dq.back()] < nums[i]) dq.pop_back();
        dq.push_back(i);
        if (i >= k - 1) res.push_back(nums[dq.front()]);
    }
    return res;
}

Hash Map

std::unordered_map / std::map
O(1) avg lookup O(n) worst case Key-Value pairs

What it is

Key-value store backed by a hash table. unordered_map gives O(1) average for all operations. map uses a red-black tree and gives O(log n) but maintains sorted order.

When to use

  • Frequency counting of elements
  • Two-sum / complement lookup
  • Caching intermediate results
  • Grouping (group anagrams, etc.)
Operationunordered_mapmap (ordered)
Insert / Erase / FindO(1) avgO(log n)
Iteration in orderNot guaranteedO(n)
SpaceO(n)O(n)
C++hash map patterns
unordered_map<int, int> freq;

// Frequency count
for (int x : nums) freq[x]++;

// Two Sum
unordered_map<int, int> seen;
for (int i = 0; i < nums.size(); i++) {
    int comp = target - nums[i];
    if (seen.count(comp)) return {seen[comp], i};
    seen[nums[i]] = i;
}

// Safe access
if (freq.find(key) != freq.end()) { /* key exists */ }
freq.count(key); // 0 or 1 for map

// Ordered map — useful for range queries
map<int, int> m;
auto it = m.lower_bound(k); // first key >= k
auto it2 = m.upper_bound(k); // first key > k
⚡ Interview Traps
  • Accessing a non-existent key via [] inserts it with value 0 — use .count() or .find()
  • Custom hash needed for pair/vector keys in unordered_map
  • Worst-case O(n) due to collisions — mention this in interviews

Hash Set

std::unordered_set / std::set
O(1) lookup No duplicates
C++hash set — dedup and membership
unordered_set<int> s;
s.insert(5);
s.count(5);   // 1 if present, 0 if not
s.erase(5);

// Longest Consecutive Sequence — O(n)
unordered_set<int> numSet(nums.begin(), nums.end());
int longest = 0;
for (int n : numSet) {
    if (!numSet.count(n - 1)) { // start of sequence
        int len = 1;
        while (numSet.count(n + len)) len++;
        longest = max(longest, len);
    }
}

Tree

Binary Tree — recursive node structure
Hierarchical DFS / BFS O(h) operations

Traversal Orders

  • Inorder (L → Root → R): sorted BST output
  • Preorder (Root → L → R): copy tree, serialize
  • Postorder (L → R → Root): delete tree, height
  • Level-order (BFS): shortest path, zigzag

Key Properties

  • Height h: O(log n) balanced, O(n) skewed
  • n nodes → at most n-1 edges
  • Full: every node has 0 or 2 children
  • Complete: filled left-to-right, last level
C++binary tree traversals + diameter
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

// Inorder — iterative
vector<int> inorder(TreeNode* root) {
    vector<int> res;
    stack<TreeNode*> st;
    TreeNode* curr = root;
    while (curr || !st.empty()) {
        while (curr) { st.push(curr); curr = curr->left; }
        curr = st.top(); st.pop();
        res.push_back(curr->val);
        curr = curr->right;
    }
    return res;
}

// Max depth / height
int maxDepth(TreeNode* root) {
    if (!root) return 0;
    return 1 + max(maxDepth(root->left), maxDepth(root->right));
}

// Diameter of binary tree
int diameter = 0;
int dfs(TreeNode* node) {
    if (!node) return 0;
    int L = dfs(node->left), R = dfs(node->right);
    diameter = max(diameter, L + R); // path through this node
    return 1 + max(L, R);
}

Binary Search Tree

Left < Root < Right — maintained property
O(log n) balanced O(n) degenerate Ordered

BST Property

Every left subtree has values smaller than root; every right subtree has values larger. Inorder traversal yields sorted order. Without balancing (AVL/RB), degrades to O(n).

Common problems

  • Validate a BST (track min/max range)
  • Lowest Common Ancestor
  • Kth smallest element (inorder)
  • Convert sorted array to BST
C++BST operations + LCA
// Search in BST
TreeNode* search(TreeNode* root, int key) {
    if (!root || root->val == key) return root;
    return key < root->val ? search(root->left, key)
                           : search(root->right, key);
}

// Validate BST
bool isValid(TreeNode* node, long lo, long hi) {
    if (!node) return true;
    if (node->val <= lo || node->val >= hi) return false;
    return isValid(node->left, lo, node->val) &&
           isValid(node->right, node->val, hi);
}
// Call: isValid(root, LONG_MIN, LONG_MAX)

// Lowest Common Ancestor (BST)
TreeNode* lca(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (p->val < root->val && q->val < root->val)
        return lca(root->left, p, q);
    if (p->val > root->val && q->val > root->val)
        return lca(root->right, p, q);
    return root; // split point — this is the LCA
}

// std::set and std::map are BST-backed (O(log n))
set<int> bst = {3, 1, 4, 1, 5}; // auto-sorted, deduped

Heap (Priority Queue)

std::priority_queue — complete binary tree property
O(log n) insert O(1) peek max/min O(log n) pop

What it is

A complete binary tree where parent ≥ children (max-heap) or parent ≤ children (min-heap). Backed by an array. priority_queue is a max-heap by default in C++.

Classic use cases

  • Top-K elements / Kth largest
  • Merge K sorted lists
  • Dijkstra's shortest path
  • Meeting rooms / task scheduler
C++heap + top-K pattern
// Max-heap (default)
priority_queue<int> maxH;
maxH.push(3); maxH.push(1); maxH.push(5);
maxH.top();   // 5 — O(1)
maxH.pop();   // removes 5 — O(log n)

// Min-heap
priority_queue<int, vector<int>, greater<int>> minH;

// Kth largest element
int findKthLargest(vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> minH;
    for (int n : nums) {
        minH.push(n);
        if (minH.size() > k) minH.pop(); // keep top K
    }
    return minH.top(); // Kth largest
}

// Custom comparator (pair: {freq, val})
auto cmp = [](pair<int,int> a, pair<int,int> b) {
    return a.first > b.first; // min-heap by frequency
};
priority_queue<pair<int,int>, vector<pair<int,int>>, decltype(cmp)> pq(cmp);

// std::make_heap, push_heap, pop_heap on raw vector
⚡ Interview Traps
  • To build a heap from n elements: O(n) — mention this over n × O(log n) push
  • Top-K with min-heap of size K is better than max-heap — O(n log K) not O(n log n)
  • Heap does NOT support O(log n) delete-by-value — use lazy deletion

Graph

Adjacency list / matrix — directed or undirected
BFS / DFS Dijkstra Topological Sort Cycle detection

Adjacency List

Space O(V+E). Best for sparse graphs. Most practical choice.

Adjacency Matrix

Space O(V²). O(1) edge lookup. Best for dense graphs.

Edge List

Just a list of edges. Used in Kruskal's MST. Easiest to sort by weight.

C++graph templates — BFS, DFS, Dijkstra, Topo Sort
int V = 7;
vector<vector<int>> adj(V);
adj[0].push_back(1); adj[0].push_back(2); // 0→1, 0→2

// DFS (recursive)
void dfs(int v, vector<bool>& vis, vector<vector<int>>& adj) {
    vis[v] = true;
    for (int u : adj[v]) if (!vis[u]) dfs(u, vis, adj);
}

// Dijkstra — SSSP for weighted graphs (no neg weights)
vector<int> dijkstra(int src, vector<vector<pair<int,int>>>& adjW) {
    int n = adjW.size();
    vector<int> dist(n, INT_MAX);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
    dist[src] = 0; pq.push({0, src});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue; // stale entry
        for (auto [v, w] : adjW[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}

// Topological Sort (Kahn's BFS)
vector<int> topoSort(int V, vector<vector<int>>& adj) {
    vector<int> indegree(V, 0), order;
    for (int u = 0; u < V; u++) for (int v : adj[u]) indegree[v]++;
    queue<int> q;
    for (int i = 0; i < V; i++) if (!indegree[i]) q.push(i);
    while (!q.empty()) {
        int u = q.front(); q.pop(); order.push_back(u);
        for (int v : adj[u]) if (--indegree[v] == 0) q.push(v);
    }
    return order; // size != V means cycle exists
}
⚡ Interview Decision Tree
  • Unweighted shortest path → BFS
  • Weighted, no neg edges → Dijkstra
  • Negative edges → Bellman-Ford
  • All-pairs shortest path → Floyd-Warshall
  • Ordering with dependencies → Topological Sort (detect cycle: size check)
  • Connected components → DFS/BFS or Union-Find

Trie

Prefix tree — O(L) insert/search where L = word length
O(L) search Prefix matching Autocomplete
C++trie implementation
struct TrieNode {
    TrieNode* children[26] = {};
    bool isEnd = false;
};

struct Trie {
    TrieNode* root = new TrieNode();

    void insert(string word) {
        TrieNode* cur = root;
        for (char c : word) {
            int idx = c - 'a';
            if (!cur->children[idx]) cur->children[idx] = new TrieNode();
            cur = cur->children[idx];
        }
        cur->isEnd = true;
    }

    bool search(string word) {
        TrieNode* cur = root;
        for (char c : word) {
            int idx = c - 'a';
            if (!cur->children[idx]) return false;
            cur = cur->children[idx];
        }
        return cur->isEnd;
    }

    bool startsWith(string prefix) {
        TrieNode* cur = root;
        for (char c : prefix) {
            int idx = c - 'a';
            if (!cur->children[idx]) return false;
            cur = cur->children[idx];
        }
        return true;
    }
};
⚡ Interview Traps
  • Space: O(ALPHABET × N × L) — mention this tradeoff vs hash map
  • Used for: Word Search II, Design Search Autocomplete, Replace Words
  • XOR Trie: store binary representations to find max XOR in O(32) per query

Disjoint Set (Union-Find)

Path compression + union by rank — nearly O(1) ops
O(α(n)) ≈ O(1) Connected components Cycle detection

What it is

Tracks a partition of elements into disjoint sets. find(x) returns the representative (root) of x's set. union(x, y) merges two sets. With path compression + union by rank, each operation is practically O(1) — Ackermann inverse α(n).

C++union-find with path compression + rank
struct DSU {
    vector<int> parent, rank;
    DSU(int n) : parent(n), rank(n, 0) {
        iota(parent.begin(), parent.end(), 0);
    }
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]); // path compression
        return parent[x];
    }
    bool unite(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false; // already same — cycle!
        if (rank[px] < rank[py]) swap(px, py);
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
        return true;
    }
    bool connected(int x, int y) { return find(x) == find(y); }
};

// Number of islands variant — DSU approach
// Kruskal's MST: sort edges, unite if not already connected
// Count components: # unique find() values after all unions
⚡ Interview Traps
  • Always use both path compression AND union by rank — not just one
  • Cycle detection: if find(u) == find(v) before uniting — cycle exists
  • Kruskal's MST, number of provinces, redundant connections are classic DSU problems

Bloom Filter

Probabilistic set — space-efficient membership test
O(k) insert/query False positives possible No false negatives Space efficient

How it works

A bit array of size m, and k independent hash functions. To insert: set k bits to 1. To query: check if all k bits are 1. False positive possible; false negative never. Cannot delete (standard).

Real-world use

  • Database query caching (avoid disk hit)
  • Chrome's malicious URL filter
  • CDN / cache membership check
  • Distributed systems deduplication
C++simple bloom filter implementation
struct BloomFilter {
    vector<bool> bits;
    int m, k; // size and number of hash functions

    BloomFilter(int m, int k) : bits(m, false), m(m), k(k) {}

    // Simulate k hash functions via double hashing
    int hash_i(string& s, int i) {
        size_t h1 = hash<string>{}(s);
        size_t h2 = hash<string>{}(s + to_string(i));
        return (h1 + i * h2) % m;
    }

    void insert(string s) {
        for (int i = 0; i < k; i++) bits[hash_i(s, i)] = true;
    }

    bool mightContain(string s) {
        for (int i = 0; i < k; i++)
            if (!bits[hash_i(s, i)]) return false; // definitely absent
        return true; // probably present (false positive possible)
    }
};
// FP rate ≈ (1 - e^(-kn/m))^k   where n = # elements inserted
Interview note: Bloom filters are a system design / knowledge question. Know the FP rate formula, why deletion is hard (use Counting Bloom Filter variant), and real-world use cases. Not typically asked as a coding problem.

LRU Cache

HashMap + Doubly Linked List — O(1) get and put
O(1) get/put Eviction policy Classic design problem

Design

Hash map for O(1) key lookup. Doubly linked list to maintain recency order — move accessed nodes to front, evict from back. The classic combination problem in interviews.

Why this combo works

  • HashMap → O(1) find the node pointer
  • DLL → O(1) remove + move to front
  • Together → O(1) for both get and put
  • Evict: always remove tail (LRU node)
C++LRU cache — full implementation
struct LRUNode {
    int key, val;
    LRUNode *prev, *next;
    LRUNode(int k, int v) : key(k), val(v), prev(nullptr), next(nullptr) {}
};

class LRUCache {
    int cap;
    unordered_map<int, LRUNode*> cache;
    LRUNode *head, *tail; // dummy sentinels

    void remove(LRUNode* node) {
        node->prev->next = node->next;
        node->next->prev = node->prev;
    }
    void insertFront(LRUNode* node) {
        node->next = head->next;
        node->prev = head;
        head->next->prev = node;
        head->next = node;
    }
public:
    LRUCache(int capacity) : cap(capacity) {
        head = new LRUNode(0,0); tail = new LRUNode(0,0);
        head->next = tail; tail->prev = head;
    }
    int get(int key) {
        if (!cache.count(key)) return -1;
        LRUNode* node = cache[key];
        remove(node); insertFront(node); // move to MRU position
        return node->val;
    }
    void put(int key, int value) {
        if (cache.count(key)) { remove(cache[key]); delete cache[key]; }
        LRUNode* node = new LRUNode(key, value);
        cache[key] = node; insertFront(node);
        if (cache.size() > cap) {
            LRUNode* lru = tail->prev;
            remove(lru); cache.erase(lru->key); delete lru;
        }
    }
};

// Easier alternative: use std::list + unordered_map in C++
// list maintains order; map stores list iterators for O(1) splice
⚡ Interview Traps
  • Dummy head/tail sentinels eliminate edge-case null checks in insert/remove
  • C++ shortcut: std::list + unordered_map<int, list::iterator> — splice() moves nodes in O(1)
  • Extend to LFU Cache: O(1) requires 3 maps + DLL per frequency
